# Inkdraft

A single-page, no-build writing prompt generator. Draw a random topic, get a 60-minute timer, and write the article before it runs out then publish it wherever you like (Substack, Medium, your own blog, etc).

Built as one self-contained `index.html` file — no npm install, no server, no dependencies beyond a couple of Google Fonts. Open it in a browser and go.

## Features

- **~155 topics** across ten categories: personal/reflective, work & productivity, technology, culture & society, money, food, creativity & writing, relationships, big ideas, health, easy/low-stakes, philosophical, political, geopolitical, and books/literature.
- **Draw Topic** button does a quick shuffle animation before landing on a topic — topics won't repeat until the full deck has been drawn once (with a manual "Reshuffle deck" option to reset early).
- **60-minute countdown timer** with Start / Pause / Reset.
- **+5 / +10 / +15 minute** buttons to extend the clock mid-sprint without losing your progress.
- Timer turns red under 5 minutes remaining, and keeps counting into negative time (with a pulsing red display) if you go over instead of just stopping.
- No backend, no tracking, no accounts, everything runs client-side.

## Usage

1. Open `index.html` in any modern browser (or visit the GitHub Pages link).
2. Click **Draw Topic** to get your prompt.
3. Click **Start** to begin the 60-minute timer.
4. Write your article in Substack, Medium, or wherever you publish.
5. Use **+5 / +10 / +15 min** if you need more time.
6. Click **Reset to 60:00** to start a fresh sprint, or **Draw Topic** again for a new prompt.
